# Ditty Revival

A Ditty-inspired lyric-to-singing video creator.

## Current prototype
- Mobile-friendly creator UI
- Lyrics editor
- Original-song selector
- Voice selector
- Background image/video upload
- Caption customization
- Live visual preview
- Mock generation flow

## Project structure

- `frontend/` — web app
- `backend/` — API placeholder for the future singing/video renderer

The actual singing synthesis and MP4 renderer are intentionally separated from the UI so they can be added without rebuilding the frontend.
